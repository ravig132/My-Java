## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/ravig132/My-Java.git
```

### 2. Open the Project

Open the cloned repository in **IntelliJ IDEA** or any Java-compatible IDE.

### 3. Select a Java Program

Choose any `.java` file you want to execute.

For example:

```text
PC30factorial.java
PC34primeNum.java
PC36fibonacci.java
PC38palindromeNum.java
Pattern1.java
```

### 4. Compile and Run

Using the terminal:

```bash
javac FileName.java
java FileName
```

Or simply run the program directly from your IDE.
